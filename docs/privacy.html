Privacy Policy

Machine Reverse Uploader. Last updated: October 22, 2026.

Machine Reverse Uploader ("the app") is a private tool operated by the owner of the Machine Reverse YouTube channel to upload and schedule that channel's own videos. The app uses YouTube API Services. By using the app you agree to the YouTube Terms of Service, and Google's handling of your data is described in the Google Privacy Policy.

What data the app accesses

With the youtube.force-ssl scope, the app reads basic information about the authorized channel (channel ID, title, upload status) and creates or updates that channel's videos, captions and thumbnails. It does not read comments, subscribers, analytics, or any other user's data.

How the data is used and stored

Data is used only to upload and schedule the channel's own videos. The OAuth refresh token is stored as an encrypted secret in the owner's private GitHub Actions settings. The app keeps only a log of uploaded video IDs and scheduled dates. No personal data is sold, shared with third parties, or used for advertising.

Revoking access

Access can be revoked at any time at Google Account permissions. After revocation the stored token stops working and is deleted.
